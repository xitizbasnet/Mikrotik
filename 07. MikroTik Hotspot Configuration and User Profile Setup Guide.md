# MikroTik Hotspot Configuration and User Profile Setup Guide

## 📘 Overview

This document explains how to configure a MikroTik Hotspot server and create user profiles for internet access authentication. It also demonstrates how to verify internet connectivity using the Windows Command Prompt and test hotspot login access from client computers.

---

# 🖥️ Part 1 — Verify Internet Connectivity on Client Computer

## Step 1: Open the Client Computer

Example client computer:

```text
accountpc
```

---

## Step 2: Open Command Prompt as Administrator

1. Search for **Command Prompt**
2. Right-click **Command Prompt**
3. Select:

```text
Run as administrator
```

---

## Step 3: Run Internet Connectivity Test

Type the following command:

```bash
ping 8.8.8.8 -t
```

Press:

```text
Enter
```

---

## ✅ Expected Result

You should see continuous ping replies similar to:

```text
Reply from 8.8.8.8
```

This confirms that the current computer is connected to the internet.

---

# 🌐 Part 2 — Configure MikroTik Hotspot

## Step 1: Open Winbox

Launch the MikroTik Winbox application.

---

## Step 2: Login to MikroTik Router

Use the following credentials:

```text
Username: admin
Password: *****
```

Click:

```text
Connect
```

---

# ⚙️ Part 3 — Configure Hotspot Server

## Navigate to Hotspot Setup

Go to:

```text
IP > Hotspot > Servers
```

Select:

```text
Hotspot Setup
```

---

## 📋 Hotspot Setup Configuration

A hotspot setup configuration dialog box will appear.

---

### Step 1: Select Hotspot Interface

Configure:

```text
Hotspot Interface: LAN
```

Click:

```text
Next
```

---

### Step 2: Configure Local Network Address

Configure the following:

```text
Local Address of Network: 192.168.1.100/24
Masquerade Network: Enable (Tick Mark)
```

Click:

```text
Next
```

---

### Step 3: Configure Address Pool

Enter the address pool ranges:

```text
192.168.1.1 - 192.168.1.100
192.168.1.101 - 192.168.1.254
```

Click:

```text
Next
```

---

### Step 4: Select Certificate

Configure:

```text
Select Certificate: none
```

Click:

```text
Next
```

---

### Step 5: Configure SMTP Server

Configure:

```text
IP Address of SMTP Server: 0.0.0.0
```

Click:

```text
Next
```

---

### Step 6: Configure DNS Servers

Enter the DNS server addresses:

```text
8.8.8.8
8.8.4.4
```

Click:

```text
Next
```

---

### Step 7: Configure DNS Name

Configure:

```text
DNS Name: www.xitiztechservices.local
```

Click:

```text
Next
```

---

### Step 8: Create Local Hotspot User

Configure:

```text
Name of Local Hotspot User: admin
Password of the User: ****
```

> ℹ️ Use the administrator password for the hotspot user.

Click:

```text
Next
```

---

# 📡 Connectivity Behavior During Hotspot Activation

After hotspot configuration is completed:

* The ping replies in the Command Prompt will stop temporarily.
* This indicates that hotspot authentication is now required before internet access is allowed.

---

# 🔍 Part 4 — Verify Hotspot Server Profile

Navigate to:

```text
Winbox > IP > Hotspot > Server Profiles
```

You will see the hotspot profile created previously.

Example configuration:

```text
Name: hsprof1
DNS Name: www.xitiztechservices.local
HTML Directory: hotspot
```

# ✅ Part 6 — Verify Internet Access Again

Return to the Command Prompt.

You should now see ping replies again:

```text
Reply from 8.8.8.8
```

This confirms that the hotspot authentication is successful and internet access is restored.

---

# 👤 Part 7 — Create Additional Hotspot Users

Navigate to:

```text
Winbox > IP > Hotspot > Users
```

Current user:

```text
admin
```

---

## ➕ Create New User

Select:

```text
New User
```

Configure the following details:

### General Settings

```text
Enabled: Enable (Tick Mark)
Server: all
Name: user1
Password: *****
Profile: default
```

Click:

```text
Apply > OK
```

---

# 🔒 Notes and Best Practices

* Always use secure passwords for hotspot users.
* Verify DNS settings before deployment.
* Ensure the hotspot interface is correctly assigned.
* Test authentication from multiple client devices.
* Keep Winbox and MikroTik RouterOS updated.
