# MikroTik Hotspot User Management Guide

## Control Internet Usage, Limit Speed, Time & Downloads on MikroTik Router

---

# 📘 Overview

This document explains how to:

* Limit internet usage time for hotspot users
* Restrict download usage (data quota)
* Monitor user session statistics
* Configure bandwidth/speed limits using User Profiles
* Assign different internet speed profiles to hotspot users

The configuration is performed using **WinBox** on a **MikroTik Router**.

---

## Step 1: Open WinBox

Open the **WinBox** application.

---

```text

```

```text

```

---

# 👥 Configure Hotspot User Usage Limits

## Navigate to Hotspot Users

Go to:

```text
IP > Hotspot > Users
```

Here we can see two users:

```text
user1
admin
```

---

# ⏱️ Set Internet Time Limit and Download Quota

## Configure User: user1

Click on:

```text
user1
```

Example:

```text
I want to control the internet usage for this user1
```

Enter the following details:

```text
Limit Uptime: 00:02:00
```

📌 Meaning:

* User can access the internet for **2 minutes**

---

```text
Limit Bytes Total: 100M
```

📌 Meaning:

* User can download a total of **100 MB**

---

Click:

```text
Apply > OK
```

# 📊 User Session Details

After login, the page will display details such as:

```text
Hi, user1@
IP Address: 192.168.1.19
Bytes Up/Down: 3.8 KiB / 248B
Connect / Left: 1s / 1m45s
Status Refresh: 1m
```

📌 Notes:

* `Connect / Left` shows:

  * Connected session time
  * Remaining allowed time
* In this example:

  * Total allowed time = **2 minutes**

---

# 🔄 Monitor Remaining Time

Refresh the page.

After refreshing, we can see that the:

```text
Connect / Left
```

time is decreasing.

---

# 🌍 Test Internet Access

Search for:

```text
connect
```

in a new browser tab.

---

# 🚫 Automatic Logout After Time Limit

After the **2-minute limit** ends:

* The user will automatically be logged out from MikroTik.

Now open the Edge browser again and search for:

```text
connect
```

It will display an error message such as:

```text
Hmmm....can't reach this page
```

---

# ⚠️ Login Attempt After Usage Limit Reached

When the user tries to log in again to the MikroTik page:

The system will display a message such as:

```text
User user1 has reached uptime limit
```

This message will appear in the MikroTik dashboard/login page.

# 🚀 Configure Internet Speed Limits

## Navigate to User Profiles

Go to:

```text
IP > Hotspot > User Profiles
```

---

# 🆕 Create New Speed Profile (256K/1024K)

## Create New Profile

Click:

```text
New
```

Enter the following settings:

```text
Name: speed-1024K
Address Pool: none
Idle Timeout: none
Keepalive Timeout: 00:02:00
Status Autorefresh: 00:01:00
Shared Users: 2
Rate Limit (rx/tx): 256K/1024K
Add MAC Cookie: Enable (tick mark)
MAC Cookie Timeout: 3d 00:00:00
```

📌 Rate Limit Explanation:

```text
256K  = Upload Speed
1024K = Download Speed
```

---

Click:

```text
Apply > OK
```

---

Go to:

```text
Name: speed2M

Idle Timeout: none

Status Autorefresh: 00:01:00
Shared Users: 2
Rate Limit (rx/tx): 1024K/2048K

```

```text
1024K = Upload Speed
2048K = Download Speed
```

---

Click:

```text

```

---

# 👤 Assign Speed Profiles to Users

## Assign Profile to user1

Go to:

```text
IP > Hotspot > Users
```

Select:

```text
user1 > General
```

Set profile:

```text
Profile: speed-1024K
```

Click:

```text
Apply > OK
```

---

## Assign Profile to admin

Select:

```text
admin > General
```

Set profile:

```text
Profile: speed2M
```

Click:

```text
Apply > OK
```

* Use strong passwords for hotspot users
* Monitor bandwidth usage regularly
* Create separate profiles for different departments/users
* Use descriptive profile names for easier management
* Backup MikroTik configurations before making major changes
