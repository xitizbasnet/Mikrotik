# How to Assign Public IP Address to WAN Interface on MikroTik Router

## 📌 Overview

This guide explains how to assign a Public IP Address to the WAN interface on a MikroTik Router using WinBox or the MikroTik Web Interface.

Assigning a public IP address to the WAN interface allows the router to communicate with external networks and the internet.

---

# 🖥️ Prerequisites

Before starting, ensure you have:

* ✅ Access to the MikroTik Router
* ✅ Administrator login credentials
* ✅ A valid Public IP Address from your ISP
* ✅ Subnet mask/CIDR notation
* ✅ WAN interface configured

---

# 🔐 Step 1: Login to MikroTik Router

1. Open **WinBox** or the MikroTik Web Interface.
2. Login using your administrator username and password.

---

# 🌐 Step 2: Open IP Address Configuration

Navigate to:

```text id="m8g2hv"
IP → Addresses
```

---

## 📋 Existing IP Address List

Inside the **Addresses** window, you can see the current list of configured IP addresses.

---

# ➕ Step 3: Add New Public IP Address

1. Click the **New (+)** button.

---

# ⚙️ Configure IP Address Details

Fill up the details as follows:

| Field     | Value               |
| --------- | ------------------- |
| Enabled   | Tick Mark           |
| Comment   | Leave Empty         |
| Address   | `192.168.11.125/24` |
| Interface | `WAN`               |

---

## 📝 Important Note

In the **Address** field, write the:

```text id="fmdg8j"
Public IP Address/Subnet Mask
```

Example:

```text id="u8s1mv"
192.168.11.125/24
```

---

# 💾 Apply Configuration

1. Click:

```text id="rr3i2f"
Apply
```

2. Click:

```text id="fjlwmj"
OK
```

---

# ✅ Configuration Successful

The Public IP Address is now successfully assigned to the WAN interface on the MikroTik Router.

---

# 🔍 Verification

To verify the configuration:

1. Go to:

```text id="g8l9zt"
IP → Addresses
```

2. Confirm that the newly assigned public IP address appears in the address list.

---

# 📚 Summary

This configuration allows the MikroTik WAN interface to:

* Connect to external networks
* Access the internet
* Support NAT, routing, and firewall configurations
* Enable public-facing services if required

---

# 🔐 Security Recommendation

For production environments:

* Use firewall rules to secure WAN access
* Disable unnecessary management services from the internet
* Restrict WinBox/Web access to trusted IP addresses
* Regularly back up MikroTik configurations
