# 🌐 MikroTik Router Configuration Guide

# 🔐 How To Allow Internet Access for Specific Devices Using MAC Address on MikroTik Router

# 1 Purpose

🎯 This document outlines the procedure for allowing internet access to a specific device using its **MAC Address** on a **MikroTik Router**.

This process is commonly used in controlled network environments where internet access is restricted and devices must be manually authorized.

The procedure ensures:

* ✅ Controlled internet access
* ✅ Device-level authentication
* ✅ Network security management
* ✅ Proper user access control

---

# 2 Verify Internet Access Restriction

## 🖥️ Client Computer Verification

### Step 1 — Open Command Prompt

Go to the client computer.

Search for:

```text
Command Prompt
```

Run as:

```text
Run as Administrator
```

---

### Step 2 — Test Internet Connectivity

Type the following command:

```bash
ping 8.8.8.8 -t
```

---

### Step 3 — Verify Ping Result

Here the ping reply will not respond properly.

It will show the message as:

```text
Destination net unreachable
```

📌 This confirms that internet access is currently blocked for the device.

---

# 3 Retrieve Device MAC Address

## 🔍 Obtain Physical Address

### Step 1 — Open Command Prompt Again

Again:

Search for:

```text
Command Prompt
```

Run as:

```text
Run as Administrator
```

---

### Step 2 — Display Network Configuration

Type the command:

```bash
ipconfig /all
```

---

### Step 3 — Locate Device Information

Here we can see the device information.

We need to search for specific details:

Under:

```text
Ethernet adapter Ethernet 0
```

Search for:

```text
Physical Address : A1:B2:C3:D4:E5:F6
```

---

> 📌 Note:
>
> The **Physical Address** is also known as the **MAC Address**.

---

### Step 4 — Copy MAC Address

Copy the MAC Address.

### Example:

```text
A1:B2:C3:D4:E5:F6
```

---

# 4 Login to MikroTik Router

## 🔐 Router Access Procedure

### Step 1 — Login to MikroTik

Now login to the MikroTik router with the user credential.

```text
Username: admin
Password: *****
```

---

### Step 2 — Authenticate

Click **Login**.

---

# 5 Configure IP Binding

## ⚙️ Add MAC Address to IP Binding

### Step 1 — Navigate to IP Binding

Go to:

```text
IP Binding
```

Select:

```text
New
```

---

### Step 2 — Fill Up the Details

Configure the following settings:

| Setting        | Value                                  |
| -------------- | -------------------------------------- |
| ✅ Enabled      | Tick mark                              |
| 📝 Comment     | Leave empty                            |
| 🔗 MAC Address | Click `+` and paste copied MAC Address |
| 🌐 Server      | All                                    |
| ⚡ Type         | Bypassed                               |

---

### Example MAC Address

```text
A1:B2:C3:D4:E5:F6
```

---

### Step 3 — Save Configuration

Click:

```text
Apply
```

Then click:

```text
OK
```

---

### Step 4 — Confirmation

Now the MAC Address is added in the IP Binding successfully.

---

# 6 Verify Internet Connectivity

## 🌐 Connectivity Verification

### Step 1 — Return to Client Computer

Go to the client computer.

Search for:

```text
Command Prompt
```

Run as:

```text
Run as Administrator
```

---

### Step 2 — Run Ping Test Again

Type the command:

```bash
ping 8.8.8.8 -t
```

---

### Step 3 — Verify Successful Reply

Here the ping reply will be seen successfully.

Example:

```text
Reply from 8.8.8.8: bytes=32 time=xxms TTL=xx
```

---

✅ This means internet access is now available for the device.

---

# 7 Conclusion

✅ The IP Binding configuration process on MikroTik allows administrators to provide internet access to authorized devices using their MAC Address.

This method helps maintain:

* 🔐 Secure network access control
* 🖥️ Device-specific authorization
* 🌐 Controlled internet availability
* ⚙️ Efficient network management

Following this procedure ensures only approved devices can access the internet within the network environment.
